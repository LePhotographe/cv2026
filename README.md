# Le bureau d'Arthur

CV interactif façon bureau des années 2000.

## Ce qui est publié

GitHub Pages sert les deux fichiers à la racine du dépôt :

- `index.html` : le site complet, en un seul fichier généré
- `CV_Arthur_Chauvineau.pdf` : le CV imprimable

## Les sources

- `source/src/` : le code (contenu du CV dans `js/data.js`, fichiers texte dans `js/fs.js`, styles dans `xp.css`)
- `source/assets/` : photo, fond d'écran, pointeurs, PDF
- `source/build.mjs` : assemble le tout
